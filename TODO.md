# Yuwa Glow - Premium Gen Z Brand Transformation Plan

## Phase 1: Content Cleanup & Structural Shift (The "De-Corporate" Phase)
- [ ] **Remove "Cinematic Page Loader"**: Eliminate the 1.8s barrier to entry. Immediate access is key for Gen Z.
- [ ] **Remove "Visionary Leadership" Section**: Move Director profiles from Homepage to About Us page to shift focus to lifestyle/product.
- [ ] **Remove Google Map & Contact Grid**: Remove the "local business" visual from the Homepage main body (keep in Footer/Contact page).
- [ ] **Simplify Hero Section**: Replace the complex carousel with a single, high-impact "Editorial" hero section (Video loop or static lifestyle image) with sharp typography.
- [ ] **Remove B2B "Stats Strip"**: "500+ Salons" speaks to distributors, not the end consumer.

## Phase 2: Visual Foundation (The "Premium" Update)
- [ ] **Color Palette Refinement**: 
    - Change Background: `Warm Cream` -> `Stark White` / `Cool Grey`.
    - Change Accent: `Orange Gold` -> `Sharp Bronze` / `Deep Charcoal`.
- [ ] **Typography Overhaul**:
    - Replace `Josefin Sans` with `Manrope` or `Inter` for a cleaner, modern sans-serif look.
    - Style `Cormorant Garamond` with italics for "Editorial" headings.
- [ ] **Card Design Update**:
    - Remove Drop Shadows (`box-shadow`) from Product and Category cards.
    - Implement "Flat Design" with fine 1px borders (`#E5E5E5`).

## Phase 3: Gen Z UX Features (The "Hook")
- [ ] **Add "Shop by Concern" Section**: Replace generic categories with problem-solution navigation (e.g., "Frizzy Hair", "Dry Skin").
- [ ] **Update Marquee**: Make the scrolling text strip faster, bolder, and more "streetwear" style.
- [ ] **Micro-Interactions**: Add "Add to Bag" hover effects and magnetic button animations.

## Phase 4: Polish & Atmosphere
- [ ] **Add Grain/Texture Overlay**: Subtle noise effect for that "film photography" aesthetic.
- [ ] **Asymmetrical Spacing**: Break the rigid grid for a more magazine-like layout.
